# Contributing

This repository is a **private portfolio/reference project** showcasing an
end-to-end MLOps solution for credit fraud detection.

It is **not an active open-source project**, and external contributions
(pull requests, issues, feature requests) are **not currently accepted**.

The code is shared publicly for demonstration and evaluation purposes only.
See the [LICENSE](LICENSE) for usage terms.

If you have questions about the project, feel free to reach out via the
repository owner's GitHub profile.
